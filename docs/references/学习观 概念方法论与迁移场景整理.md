## 第一部分：概念清单

### 一、认知与世界模型（01-05 节）

| 概念 | 简洁定义 |
|---|---|
| 情况 | 可被单独识别的经验片段，认识世界的基本单元。 |
| 现象 / 对象 | 被注意并独立出来的具体经验片段（对象层中的具体事物）。 |
| 经验 | 已明确信息推测任务、但未必体现规律的下层材料；是从现实中提炼并编码过的"因果"片段。 |
| 物质世界 | 不依赖意识而存在的客观世界，是经验的来源。 |
| 经验预测 | 用过去的经验去推测未见情况的能力与行为；认识世界以生存避害为目的。 |
| 类化应对 | 把新情况归入已有类别，从而调用该类既有的应对方式；对同一类情况采取相同应对。 |
| 抽象 | 比较多个具体现象、剔除差异属性、提取共有属性，以渐构判别模型的过程。 |
| 概念 | 对一类现象共有属性的概括，可作思维的最小单元；概念分正概念与负概念（非A）。 |
| 判别模型 | 判断一个现象是否属于某概念（A 或非 A）的模型，由内涵（共有属性）与外延（对象群）构成。 |
| 外延 | 概念所代表的对象群。 |
| 内涵 | 判断某对象是否属于该概念所依据的共有属性集合。 |
| 具象层 / 抽象层 | 概念金字塔中的两个层级；具象层贴近具体对象，抽象层涵盖更广的共性。 |
| 模型预测 | 用渐构出的模型对未见情况进行推测的行为。 |
| 压缩能力 | 从多个已见情况中提取共有规律、删除冗余信息的能力。 |
| 泛化能力 | 将规律应用于未见情况的能力；是验证学习成果的核心标准。 |
| 知识 | 一类普遍现象的规律（可泛化模型），区别于只描述单一情况的信息。 |
| 信息 | 对单一特殊情况的描述（如"嬴政死了"），无需渐构模型。 |

### 二、概念与层级结构（04-10 节）

| 概念 | 简洁定义 |
|---|---|
| 概念金字塔 | 概念按抽象程度层层嵌套形成的层级结构（对象层→共象层→更高抽象层）。 |
| 绝对层级 / 相对层级 | 概念的抽象层级既可按固定层次看（绝对），也可相对另一概念看（相对）。 |
| 对象层 | 概念金字塔最底层的具体对象。 |
| 共象层 | 对象层之上共享共有属性的一层；模型选择时应尽量使共象层低。 |
| 下上结构 | 知识由下层（具体对象）与上层（抽象规律）组成的双层结构。 |
| 概念世界 | 人脑中以概念及其关系构成的内在世界，独立于物质世界与语言世界。 |
| 概念遮蔽 | 既有概念体系阻碍看到新现象、新关系的现象。 |
| 大类 / 小类概念 | 外延大的类别（大类）与外延小的类别（小类）；大类提供框架，小类提供精度。 |
| 记忆编码 | 把信息存入记忆的过程，分为感觉、感知、认知三阶段。 |
| 自主化 | 反复练习后把意识处理的过程转交给自主（无意识）系统，从而释放工作记忆。 |
| 内隐记忆 / 外显记忆 | 不经意识提取的记忆 / 可被意识回想与表达的记忆。 |
| 知识诅咒 | 一旦自己掌握了某知识，就难以想象他人不知道的状态。 |
| 现象还原 / 编码回撤 | 回到现象本身重新审视、撤销原有编码，以突破概念遮蔽。 |
| 重新归类 / 编码转换 | 用新的概念体系重新归类现象。 |
| 组块化 | 将多个信息单元组合成更大的组块，以扩展有限的工作记忆容量。 |
| 类固有观 | 误以为概念是先天的、本就存在的，而非人构造出来的观点。 |
| 借真袒权 | 借"真实存在"之名，为构造的概念赋予权威地位的现象。 |
| 关系囊括性 | 以概念所能囊括的关系广度作为概念是否可接受、是否值得使用的依据。 |
| 类别固有性 | 将类别本身当作固有实体看待的倾向。 |
| 先天概念 | 演化或经验中天然形成的概念。 |
| 依存概念 | 依赖其他概念才能定义的概念（如左/右相互依存）。 |

### 三、理论、范式与科学（11-13 节）

| 概念 | 简洁定义 |
|---|---|
| 中介概念 | 联结主体与客体、组织经验的概念框架。 |
| 主体 / 客体 | 认识者 / 被认识的对象。 |
| 规律 | 能被下层所有对应关系共享的映射关系。 |
| 异化 | 人构造的概念反过来支配、束缚人的现象。 |

| 范式转换 | 主体框架发生根本改变，旧问题被重新定义甚至消失的知识革新过程。 |
| 三大挑战 | 线索缺席（未见线索）、记忆容量有限、经验稀缺——纯经验学习难以突破的三类困难。 |
| 代理机制 / 概念代理 | 用符号（概念代理）代表不在场的对象，实现跨时空整合与扩展工作记忆。 |
| 跨时空整合 | 把不同时间、空间获得的经验借助符号整合到同一思维空间。 |

### 四、语言与符号（14-16 节）

| 概念 | 简洁定义 |
|---|---|
| 能指 / 所指 | 语言符号本身（能指）与符号所指代的概念或对象（所指）。 |
| 符号 / 含义 | 符号是语言的物理形式；含义是符号所指的概念内容，二者并非固定对应。 |
| 指代关系 | 语言符号与概念之间的对应关系，随语境变化。 |
| 语义变迁 | 同一符号在不同时代或语境中的含义发生变化。 |
| 偷换概念 | 利用符号与含义的非固定对应关系，在论证中暗中替换概念。 |
| 语言世界 | 由语言符号及其组合规则构成的世界，可扩展概念世界。 |
| 三大世界 | 物质世界、意义（概念）世界、语言世界。 |
| 自然语言 / 数学语言 / 编程语言 / 图形语言 | 不同精度的符号系统；数学语言精确但抽象，自然语言灵活但模糊。 |
| 记言代学 | 把记住语言表述当作学会知识（只记符号，未渐构概念）。 |
| 只记名称 / 只记描述 | 仅记住概念的名称，或仅记住语言的描述，而没掌握概念的内涵。 |
| 言存义空 | 记住了语言符号但没有相应的概念意义。 |
| 义存言空 | 有概念意义但缺乏语言符号表达。 |
| 知识坍缩 | 知识的双层结构坍塌为单层：下层丢失、上层丢失或下上错配。 |

### 五、量化学习：模型与映射（17-20 节）

| 概念 | 简洁定义 |
|---|---|
| 信息推测 | 由一个（输入）信息推测另一个（输出）信息的行为；是学习任务的基本形式。 |
| 输入 / 输出 | 推测依据 / 推测目标（数学语言中的自变量 / 因变量）。 |
| 维度 | 输入或输出空间的组成成分（多因素变量）。 |
| 常量 / 变量 | 具体取值 / 可取多种值的抽象单元。 |
| 空间 | 某变量所有可能取值的集合。 |
| 对应关系 | 常量到常量的具体对应（下层材料所展示）。 |
| 映射关系 | 变量（集合）之间的规律性对应（上层规律）。 |
| 联结模型 | 从输入空间到输出空间的映射规律模型，用于推测未见情况。 |
| 归纳 | 从多个输入常量与输出常量的对应关系中寻找共有关系的过程。 |
| 表征 | 为简化归纳而对对象做的中间编码（中介变量）。 |
| 判联错配 | 把判别模型与联结模型用错对象（如把定义当规律、把规律当定义）造成的推理谬误。 |
| 绝对 / 相对输入空间 | 判别模型输入可区分绝对类别（绝对输入空间）或仅相对比较（相对输入空间）。 |
| 二类 / 多类输出 | 判别模型输出两类（A/非A）或多类结果。 |

### 六、学习与记忆的界定（21-24 节）

| 概念 | 简洁定义 |
|---|---|
| 学习（一般定义） | 塑造泛化未见情况能力的行为。 |
| 学习（标准定义） | 渐构可泛化模型的行为。 |
| 记忆 | 塑造重现已见情况能力的行为；成果是信息的复制。 |
| 机械记忆 | 把本该用于学习的语言材料仅用于记忆。 |
| 习得性无助 | 长期努力无果后渐构出"努力也不会改变结果"的模型，进而放弃尝试。 |
| E 类学生（Exhausted） | 看似"勤奋但不聪明"，实因错误的学习认识与习惯而成绩不佳。 |
| T 类学生（Talented） | 看似"聪明但不勤奋"，实因不自知的高效学习习惯而成绩不差。 |
| 四维框架 | 划分学习类型的四个维度：创继、下上、主体、复用。 |
| 创验学习 | 创造并验证可泛化模型（科研是其子类）。 |
| 继承学习 | 重建他人的可泛化模型。 |
| 自下学习 | 从下层具体现象出发向上层抽象规律渐构。 |
| 自上学习 | 从上层抽象规律出发向下层具体现象渐构。 |
| 机器学习 / 人脑学习 | 由机器 / 人脑作为实施者的渐构；二者任务目标一致、技术实现不同。 |
| 内隐学习 / 外显学习 | 由人脑自主系统 / 意识系统实施的渐构。 |
| 零基学习 / 迁移学习 | 不复用既有模型 / 复用既有模型的渐构。 |
| 正迁移 / 负迁移学习 | 正确复用既有模型使进度变快 / 错误复用使进度变慢、结果错误。 |
| 先天学习能力 | 出生即有的好奇心、观察与归纳冲动。 |
| 后天学习能力 | 以语言材料为主、需后天训练的学习能力（自上学习）。 |

### 七、学习材料体系（26-33 节）

| 概念 | 简洁定义 |
|---|---|
| 认识材料 | 主体认识客体所用的材料，含记忆材料与学习材料。 |
| 记忆材料 / 学习材料 | 用于原样保存重现的材料 / 用于渐构可泛化模型的材料（取决于使用目的）。 |
| 下层材料 | 展现输入常量到输出常量对应关系的材料（数据、经验、例子）。 |
| 上层材料 | 展现输入空间到输出空间映射规律的材料（规述）。 |
| 数据 / 经验 / 例子 | 尚未明确推测任务 / 已明确任务但未必体现规律 / 体现规律的具体推测过程。 |
| 规述 / 例述 | 描述规律的上层材料 / 叙述例子的下层材料。 |
| 抽编寻归 | 使用下层材料的方法：抽象、编码、寻因、归纳。 |
| 旧义重组 | 依据材料给出的组合方式，用已有概念重组出新概念（属加种差）。 |
| 词络约束 | 借一个词在众多语句中受到的多重约束确定其概念内涵。 |
| 语料 | 包含待学词语言用法的上层材料。 |
| 表述转换 | 将知识的一种表述转换为另一种表述（如"有毒"→"会引发不良反应"）。 |
| 言不尽性 | 语言材料无法覆盖知识全部侧面的特性。 |
| 解释链 / 解释链循环 / 解释链触底 | 用 B 解释 A、C 解释 B 的链条；A↔B 循环；无更基础概念可解释的末端。 |
| 例规编排 / 规例编排 | 先例后规 / 先规后例的下上结合顺序。 |
| 下上对齐 / 排版对齐 | 上层概念在下层材料中都有对应现象 / 对应位置一致。 |
| 模型验证 | 用学习材料之外的未见情况验证模型可泛化性的环节。 |
| 验证材料 / 验证反馈 | 用于评估模型表现的下层材料 / 验证所得指导下次建构的反馈。 |
| 习题 | 可被文字化的验证材料。 |
| 例习循环 / 遗例转习 | 把多余例子当习题用 / 把遗忘的例子当习题用。 |
| 判别材料 / 联结材料 | 专门渐构判别模型 / 联结模型的学习材料。 |
| 内涵描述 | 直接表述共有属性的上层材料。 |
| 特征 | 内涵（共有属性）中的单个判别依据。 |
| 特征描述 / 特征拆分 | 直接描述单一特征的材料 / 从内涵中拆出特征的行为。 |
| 特征对比 / 特征类比 | 对比异同特征 / 类比相似特征以学习概念。 |
| 判别例述 / 正例 / 负例 | 交代现象是（不是）某概念的例述 / 输出为正概念 / 输出为负概念。 |
| 对比例组 | 一个例子同时是 A 正例与 B 负例，另一个反之，用于界定概念边界。 |
| 外延对比 | 比较两个概念外延（集合）的相等、包含、相交、互斥关系。 |
| 因素材料 | 交代知识输入、输出、中介（表征）变量是什么的联结材料。 |
| 关系材料 | 交代输出变量如何随输入变量变化的联结材料。 |
| 关系类型 | 映射关系的基本子类：常量映射、正相关、负相关、线性、非线性、正比、反比、复合关系。 |
| 常量映射 | 输入空间中每个元素都对应同一输出的映射（如"人皆有一死"）。 |
| 依托语言符号 / 直接渐构 | 靠记忆公式语言保存映射 / 不借语言直接在脑中形成映射。 |
| 性质 / 性质材料 | 附属在类别上、使该类对象必然对应特定结论的东西 / 交代某类具有何性质的材料。 |
| 特征 vs 性质 | 同一属性用作判别条件是特征，用于给出必然结论是性质。 |
| 分段例组 | 把复合关系拆成多个基础关系类型分别举例的一组例子。 |

## 第二部分：方法论

### 一、认识与建模类

| 方法名称 | 适用场景 | 核心步骤 / 要点 |
|---|---|---|
| 经验预测 | 面对未见情况做决策 | 1. 从已见经验中提取规律；2. 将新情况归入已知类别；3. 用该类别的应对方式推测处理。 |
| 类化应对 | 新情况需要快速反应 | 1. 识别新情况的类别归属；2. 调用该类别的既有应对；3. 验证反应是否有效。 |
| 模型预测与验证 | 任何学习新知识的过程 | 1. 渐构模型（从经验中提取共性）；2. 用未见情况验证；3. 泛化失败则回炉修正。 |
| 类对象化 | 想让抽象概念参与经验预测 | 把"类"当作对象处理（如把"人"当对象），使概念可被代入日常经验。 |
| 模型选择两必一尽 | 选择概念的抽象层级 | 必须先能判别现象归属（外延清晰）、必须能覆盖足够多的现象（内涵够用），共象层尽量低以便贴近对象。 |
| 组块化 | 工作记忆超载时 | 1. 将零散信息按结构组织为组块；2. 为组块命名（概念化）；3. 反复调用使组块自动化。 |
| 现象还原 + 重新归类 | 被既有概念遮蔽、无法进步 | 1. 回到原始现象（编码回撤）；2. 尝试新的归类方式（编码转换）；3. 重建概念体系。 |
| 以关系囊括性为依据 | 判断是否接受一个新概念 | 1. 检验该概念能囊括的关系范围；2. 与既有概念比较囊括力；3. 选关系囊括性更强者。 |
| 多概念体系分析 | 单一框架解释不了现象 | 1. 用不同概念体系（如不同学科视角）分析同一现象；2. 对比各体系解释力；3. 保留能覆盖更多现象的框架。 |
| 主体框架革新 | 知识体系陈旧、范式转换前 | 1. 觉察自身主体框架（概念 + 价值观）；2. 主动引入新框架审视旧问题；3. 借范式转换重构问题空间。 |
| 概念代理 / 符号超验思考 | 处理不可见、跨时空、超记忆容量的问题 | 1. 用符号代理不在场的对象；2. 按语言组合规则重组符号；3. 在符号层完成跨时空整合与推理。 |

### 二、学习流程类

| 方法名称 | 适用场景 | 核心步骤 / 要点 |
|---|---|---|
| 创验学习流程 | 从零创造新知识（研究、探索） | 1. 搜集数据（直接/间接）；2. 抽象类化出概念；3. 建构输入→输出关系的模型猜想；4. 用未见情况验证；失败则返回 1-3 步迭代。 |
| 继承学习流程 | 向他人/教材学已有知识 | 1. 获取材料；2. 理解语义；3. 继承判别模型（明确概念外延）；4. 继承联结模型（明确映射）；5. 比对模型（判断是否一致）；失败则返回对应步骤。 |
| 自下学习（抽编寻归） | 从具体案例/经验中提炼规律 | 1. 抽象（比较现象取共有属性）；2. 编码（用判别模型归类现象）；3. 寻因（确定输入、输出变量）；4. 归纳（找对应关系中的共有映射）；最后连接下上两层成模型。 |
| 自上学习（旧义重组 + 词络约束） | 直接学习抽象定义、公式、理论 | 旧义重组：按"属+种差"用已有概念组合出新概念；词络约束：借多语句的隐性关系网络锁定概念内涵。 |
| 语言学习四环节 | 学任何基于语言的知识 | 1. 理解语义（划分成分、定多义词）；2. 组织材料（按判别/联结目标筛选）；3. 渐构模型；4. 建立指代（把符号对应到概念）。 |
| 避免记言代学 | 读教材、看课程时 | 自问：我记住的是语言符号，还是能判别现象、能推测未见？以能否泛化作为学没学会的判据。 |
| 知识坍缩自查 | 学完知识却不会用 | 检查三层：是否丢失下层（只会背规律、认不出实例）？是否丢失上层（只会模仿例子、不会泛化）？是否下上错配（例与规对不上）？ |
| 明确输入输出第一原则 | 面对任何待学知识 | 1. 先问：这个知识的输入（推测依据）与输出（推测目标）是什么？2. 用数学语言形式化表述；3. 再决定建判别模型还是联结模型。 |
| 判别 + 联结模型分建 | 学概念和规律 | 判别模型解决"是什么/是不是"（内涵、外延）；联结模型解决"怎么推"（映射）；分开渐构、避免判联错配。 |
| 下上结合 | 系统学习一个知识 | 1. 既有例子也有规律时，做下上对齐（上层概念在下层都有对应现象）；2. 选编排顺序：演讲/科普用例规（熟悉→疑惑→明朗），教材/汇报用规例（定向→空泛→印证）；3. 排版对齐降低理解负担。 |

### 三、材料运用与验证类

| 方法名称 | 适用场景 | 核心步骤 / 要点 |
|---|---|---|
| 例习循环 | 教材例子多、习题少 | 1. 先理解规述 + 1-2 个例子；2. 把后续例子遮住答案当习题推测；3. 核对后把例子拿回来和前面例子一起归纳。 |
| 遗例转习 | 例子读过已遗忘 | 把遗忘细节的例子当新习题做，避免"记答案冒充推测"。 |
| 特征拆分 | 内涵复杂、容易漏判 | 1. 把内涵描述拆成若干"特征"（可用"某某性"命名）；2. 用特征数量提醒自己逐一比对；3. 全部满足才判为该概念。 |
| 特征对比 / 对比例组 / 外延对比 | 区分相似概念（如矩形 vs 平行四边形） | 1. 列出相同特征与不同特征；2. 用对比例组（A正例&B负例 + B正例&A负例）界定边界；3. 用外延（集合）关系确认包含、相交、互斥。 |
| 正负例结合 | 学习任何概念 | 既看正例（是什么）也看负例（不是什么）；负例常比正例更能划清边界。 |
| 模型验证循环 | 任何学习方式都必经 | 1. 从输入空间随机挑未见对象；2. 用模型推测输出；3. 与实际结果比对得到验证反馈；4. 以反馈修正模型，循环至泛化达标。 |
| 依托语言符号 vs 直接渐构 | 选择学外显/内隐知识 | 公式类外显知识可记语言表述（快、准、但易忘、受工作记忆限制）；技能/听力/对话类需直接渐构（慢但稳定、快、容量大）；按速度/精度/成本取舍。 |

### 四、学习诊断与工具类

| 方法名称 | 适用场景 | 核心步骤 / 要点 |
|---|---|---|
| 学习诊断五步循环 | 系统提升继承学习效率 | 描述知识 → 评估学况 → 制定材料 → 继承模型 → 验证模型；验证反馈后回到"评估学况"继续循环，以模型为单位推进。 |
| 渐构靶图 | 记录与推进一个知识的学习 | 1. 上层写输入/输出概念名、内涵表述、映射规律表述；2. 下层积累具体推测（输入常量→输出常量）；3. 用下层之外的新情况做验证材料；4. 验证后加入靶图并更新三个表述。 |
| 渐构段落笔记法 | 记笔记、整理学习材料 | 用"# + 字母 + 颜色"标记材料类型（#e 例述、#t 迁移、#v 验证、#d 描述等），段落名用 ≤4 字锚点，先预判类型再阅读。 |
| AI 辅助生成学习材料 | 缺例子/习题/讲解时 | 把本书理论框架输入大模型，请其按判别/联结模型生成例子、习题、特征对比、类比，并鉴别其正确性。 |

| 五步速通 SOP | 进入任何新领域 | 1. 描述知识（用判别/联结模型把知识形式化）；2. 评估学况（定位误区与偏好）；3. 制定材料（按八类型配上料:下料）；4. 继承模型（建判别/联结模型）；5. 验证模型（未见情况验收）→ 回到 2 循环。 | Learning-New-Field-5Step-SOP.md / Learning-Anything-Fast-SOP-AI-Ready.md |
| 八类型分型 + 材料配方 | 拿到任何学习目标 | 先把目标分型（记忆/判别/联结/思考/运动/语言/隐性经验/信息型），再按各型配比安排上料与下料，配三档验收题；分型错了 90% 的练习方向就错了。 | Learning-Anything-Fast-SOP-AI-Ready.md / 各路径文件 |

| 材料缺口清单法 | 学得慢、卡住时 | 按三类找缺口：成品样例（别人做过的完整范例）、失败反例（判别模型核心材料）、自己的实战录像（隐性经验验收）；三个缺口都不用买课，用公开素材+自产可填。 | Learning-Diagnostic-Self-Sample-01.md |

#### 2. 六类学习路径跑通版

| 方法名称 | 适用场景 | 核心步骤 / 要点 | 出处 |
|---|---|---|---|
| 判别模型学习法 | 学"是什么/是不是"类知识 | 1. 正例 + 反例 + 边界例三件套齐备；2. 判断互斥还是多重判别；3. 建边界例库；4. 四类归因定位卡点；5. 验收四轮（见未见情况、换领域对象）。 | Discrimination-Model-Learning-Path.md |
| 思考型变式训练法 | 解题、推理类技能 | 1. 识别捷径记忆（答对但不会）；2. 用变式五维度（换数字/包装/问法/干扰/条件）出变式题；3. 口述推理链暴露断点；4. 按节点图补漏。 | Thinking-Skill-Learning-Path.md |
| 运动型反馈环建法 | 运动、操作类技能 | 1. 定档（A 自带反馈/B 需外挂/C 延迟反馈）；2. 分层（感知/执行/稳定）定位缺口；3. 建最短延迟反馈环（谁/何时/怎么判对错）；4. 慢练才能学、快只能验；5. 一次只改一个变量；6. 录像回看。 | Motor-Skill-Learning-Path.md |
| 语言型四维分离法 | 学外语、表达类 | 1. 听说读写四维分离分别练；2. 认清被动词汇≠主动词汇；3. 走输出三台阶（跟读→复述→即兴）；4. 逐级撤辅助 L1-L4；5. 输入难度压到能懂七成 + 保证主动产出量，触发质变点。 | Language-Type-Learning-Path.md |
| 决策类经验积累法 | 管理、投资等隐性经验 | 1. 定档（高频/低频/专业判断）；2. 分层查缺（模式识别/权衡规则/行动惯例）；3. 六行决策日志；4. 坏决策≠坏结果，只复盘决策质量；5. 三个反馈加速器（拆小/借例/预写）；6. 概率化表达。 | Decision-Type-Learning-Path.md |
| 信息型建索引法 | 知识管理、资料类 | 1. 三问判据（能不能查/会不会变/使用频率）决定学还是建索引；2. 只建索引三要素（名称/入口/有效期）；3. 目标 30 秒内可查；4. 双向升级规则：用三次以上升级为记忆型，查五次记不住降级为信息型。 | Information-Type-Learning-Path.md / Information-Type-Organize-and-Retrieve.md |

#### 3. 元能力训练法

#### 4. AI 协作学习法

| 方法名称 | 适用场景 | 核心步骤 / 要点 | 出处 |
|---|---|---|---|
| AI 分工三层法 | 用 AI 辅助任何学习 | 按类型分工：记忆/信息型→让 AI 替记替查；判别/联结型→让 AI 出题出料；思考/运动/语言型→AI 只当陪练和镜子，绝不替做。 | AI-Handoff-by-Learning-Type.md |
| AI 要题不要答案 | 用 AI 生成练习 | 让 AI 生成变式题、反例、边界例、陪练脚本、随机抽题，而不是给答案；给答案会绕过学习本身。 | AI-Handoff-by-Learning-Type.md |
| 撤 AI 验收法 | 验证 AI 辅助学习成效 | 学完后把 AI 拿走，独立完成一次任务；做不出来＝只会操作 AI，不是会该技能。 | AI-Handoff-by-Learning-Type.md |
| 学习任务卡 | 给 AI 的标准输入格式 | 把学习目标写成任务卡（靶、分型、材料配方、验收题），作为 AI 生成学习材料的输入载体；也是未来一键生成器的接口。 | Learning-Anything-Fast-SOP-AI-Ready.md / Learning-Framework-More-Uses.md |

## 第三部分：可迁移场景

### 1. 工作与职场

| 场景 | 迁移思路 |
|---|---|
| 汇报与沟通 | 用"规例编排"：先给结论（上层规律），再展开细节（下层例子），避免韩梅式的"先细节后主旨"；按听者的知识结构决定抽象层级。 |
| 写周报/方案 | 明确输入输出：先定义要解决什么问题（输入）与交付什么结果（输出），再组织材料；用"主旨概述→细节展开"结构。 |
| 向上管理 / 申请资源 | 套用"先主旨、后细节"表达结构；用正例负例帮助对方理解新提议。 |
| 知识付费与培训 | 理解付费买的是"学习材料"而非知识本身，据此评判课程好坏（例子的抽象层级、下上对齐、正负例是否齐备）。 |
| 新人培养 / 带教 | 按继承学习五步流程设计：给材料→帮他理解语义→确认判别模型→确认联结模型→用验证材料测掌握；识别"记言代学"的假学会。 |

### 2. 学习与应试

| 场景 | 迁移思路 |
|---|---|
| 读教材 / 啃论文 | 先明确泛化目标：这知识要建判别模型还是联结模型？把内涵拆特征、用对比例组区分相似概念（如"相关 vs 因果"）。 |
| 备考复习 | 用"例习循环"把例题变习题；用"遗例转习"对抗记忆冒充理解；用验证材料（未见题）检验掌握。 |
| 背单词 / 学语法 | 对话场景用直接渐构（大量输入训练语感），考试场景可依托规则记忆；明白"能重现 ≠ 能泛化"。 |
| 学数学/编程 | 用自上学习 + 下上对齐：先吃透定义（内涵/特征），再配足贴近对象层的例子；警惕"仅有上层、没有下层"的半会不会。 |
| 听课 / 看视频 | 判断材料类型：哪些是规述、哪些是例述、哪些是验证材料；主动组织材料而非"顺序阅读、通篇记住"。 |

### 3. 编程与技术

| 场景 | 迁移思路 |
|---|---|
| 学习新框架 / 新语言 | 把文档当上层材料：先建判别模型（这是不是 X 的 API/概念）再建联结模型（输入输出如何映射）；用官方示例做下上对齐，用自写 demo 做验证。 |
| Debug / 排障 | 用"信息推测"建模：输入（症状）→输出（根因）；用负例缩小候选空间；避免"只记示例"导致只认见过的报错。 |
| 代码评审 / 方案选型 | 用"特征对比"列不同方案的相同/不同特征，用对比例组界定边界（A 行 B 不行的场景 + 反之）；避免混淆"特征"与"性质"。 |
| 迁移学习 / 复用旧代码 | 正迁移：识别可复用结构再拆分重组；负迁移：警惕旧 API 习惯在新技术上"带偏"（负迁移学习）。 |
| 用 AI 编程 | 明确输入输出给模型（任务描述 = 输入，验收标准 = 输出）；让 AI 生成正负例、特征对比等学习材料（对应书中"靠 AI 生成材料"）。 |

### 4. 投资与研究

| 场景 | 迁移思路 |
|---|---|
| 投资研究 | 严格区分"信息"（单一事件）与"知识"（普遍规律）；警惕用少数个案归纳出"以偏概全"的规律；用未见情况（样本外）验证模型。 |
| 行业分析 | 先定输入输出：什么因素（输入）可推测什么指标（输出）；用因素材料列变量、用关系材料定方向（正/负相关、非线性）；警惕常量映射冒充规律。 |
| 学术研究 | 创验学习流程：搜集数据→抽象类化→建模→验证；区分"自上创验"（数学式演绎）与"自下创验"（实验归纳）；明白科学定律"只能验证不能证明"。 |
| 避免范式陷阱 | 用"主体框架"概念审视自己的研究预设；范式转换时旧问题可能被重新定义（知识革新）。 |

### 5. 沟通、教学与育儿

| 场景 | 迁移思路 |
|---|---|
| 演讲 / 公众号写作 | 用"例规编排"制造熟悉→疑惑→明朗的顿悟感；但保证上层归纳有新知，避免"正确的废话"。 |
| 给孩子讲解知识 | 例子贴近对象层（孩子熟悉的层级）；避免只给上层材料（抽象表述让孩子"无处发力"）；警惕"不适教育"用背诵覆盖先天好奇心。 |
| 家长言传身教 | 明白家长语料会通过"词络约束"传递三观（"不好好学习找不到好工作"暗含职业贵贱）；慎选日常话语。 |
| 自学新领域 | 从"不适教育"中识别自己被改造的学习观：混淆学习与读书、科学权威、验证与评价、概念与语言；重建以"渐构模型"为目标的元认知。 |

### 6. AI 与自我提升

| 场景 | 迁移思路 |
|---|---|
| 理解机器学习 | 用书中定义理解机器学习的任务目标（渐构可泛化模型），与人的学习互证；输入/输出、映射、判别/联结都是通用数学语言而非 ML 专属。 |
| 提示词工程 | 用"因素材料 + 关系材料"思想写 prompt：明确输入变量、输出变量与映射规则；用正负例约束大模型输出。 |
| 自我认知 / 克服习得性无助 | 用"模型"视角分析：是否渐构了"努力无用"模型？用验证反馈打破错误模型（T/E 类学生分析）。 |
| 元学习（学习如何学习） | 把自己当"学习诊断师"：用五步循环（描述→评估→制定→继承→验证）复盘任何一次学习；用渐构靶图管理知识结构。 |

### （一）学习与记忆的底层区分

| 要点 | 核心内容 | 出处 |
|---|---|---|
| 记忆两大弊端 | 容量有限、难以集齐——记忆无法承载"学会"的目标，仅靠记忆不足以应对大量知识。 | Get笔记 d.biji.com/GXBSgTyXoIzMZpeE |
| 学习的定义 | 从有限例子中找出问题与答案之间的规律；规律即知识。学习不是记住答案，而是从例子中提取可泛化的映射规律。 | Get笔记 d.biji.com/GXBSgTyXoIzMZpeE |
| 费曼判据 | 无法用简单语言描述所学内容，就没真正学会；"能讲出来"是检验是否掌握规律的有效判据。 | Get笔记 d.biji.com/GXBSgTyXoIzMZpeE |
| 知识描述 ≠ 知识本身 | 只记住文字描述是"感觉懂了"；真正学习靠大量例子重塑大脑链接，描述只是指路牌，不是知识本身。 | Get笔记 d.biji.com/GXBSgTyXoIzMZpeE |
| 华罗庚读厚读薄 | 读厚＝集齐大量例子；读薄＝把例子压缩成规律；最后拿未见的问题验证规律是否成立——与《学习观》"例子→规律→未见情况验证"同构。 | Get笔记 d.biji.com/GXBSgTyXoIzMZpeE |

### （二）分而治之解题法

| 要点 | 核心内容 | 出处 |
|---|---|---|
| 组合爆炸 | 3 种知识→7 种组合，20 种知识→100 万种组合：知识数量线性增长时，组合数指数爆炸，直接整体学习不可能。 | Get笔记 d.biji.com/GXBSgTyXoIzMZpeE |
| 意识单任务 | 意识一次只处理一个思考问题，无法同时承载复杂大问题；大问题必须拆解。 | Get笔记 d.biji.com/GXBSgTyXoIzMZpeE |
| 拆分为已掌握小知识 | 把大问题拆成已掌握小知识的组合，先解决每个小知识，再组合出整体答案；例子需求量从指数级降到线性级。 | Get笔记 d.biji.com/GXBSgTyXoIzMZpeE |
| 二阶知识 | 拆分大知识的能力本身是需要学习的二阶知识；可正拆（大→小）也可逆拆（小→大）；子知识彼此独立时拆分效率最高。 | Get笔记 d.biji.com/GXBSgTyXoIzMZpeE |

### （三）思维导图实操四步

| 步骤 | 核心内容 | 出处 |
|---|---|---|
| 1. 搜集例子 | 先集齐足量具体例子（读厚），避免凭空画图。 | Get笔记 d.biji.com/GXBSgTyXoIzMZpeE |
| 2. 明确输入输出 | 用自我提问明确每个知识的输入与输出（这个知识解决什么问题、由什么推得什么）。 | Get笔记 d.biji.com/GXBSgTyXoIzMZpeE |
| 3. 提炼共性压缩信息 | 从例子中提炼共性，压缩成规律（读薄），形成导图主干。 | Get笔记 d.biji.com/GXBSgTyXoIzMZpeE |
| 4. 持续拆分直到已知 | 不断把节点拆到已掌握的小知识为止，让整张图都建立在已有认知之上。 | Get笔记 d.biji.com/GXBSgTyXoIzMZpeE |
